# 🛡️ SkyShield

SkyShield is an AI-powered security alert assistant built on Microsoft Azure.
It analyzes security alerts, extracts key insights, assigns risk scores,
supports multi-language translation, and processes image-based alerts.

## Features
- Alert explanation using Azure AI Language
- Risk scoring for prioritization
- Multi-language translation using Azure Translator
- Image-based alert analysis using Azure Computer Vision

## Tech Stack
- Python
- Streamlit
- Azure AI Language
- Azure Computer Vision
- Azure Translator
